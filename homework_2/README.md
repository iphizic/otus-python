# Homework 2

Консольное приложение "Телефонная книга" с текстовым интерфейсом на `urwid`. Программа позволяет хранить контакты в JSON-файле, просматривать список записей, добавлять новые контакты, редактировать существующие и выполнять поиск по полям.

## Возможности

- загрузка контактов из JSON-файла;
- создание нового файла, если он отсутствует;
- просмотр списка контактов;
- добавление контакта;
- редактирование контакта;
- удаление контакта;
- поиск по имени, номеру телефона и комментарию;
- сохранение данных при выходе.

## Структура проекта

- `main.py` - точка входа в приложение;
- `controller.py` - логика управления приложением;
- `view.py` - формы и элементы интерфейса;
- `model.py` - экспорт модели данных;
- `db_class.py` - класс базы контактов и работа с JSON;
- `contact_class.py` - класс контакта;
- `exceptions.py` - пользовательские исключения;
- `contacts.json` - пример файла с контактами.

## Требования

- Python 3.10+;
- пакет `urwid`.

## Установка зависимости

```bash
pip install urwid
```

## Запуск

Запускать из директории `homework_2`:

```bash
python main.py
```

После старта программа предложит указать путь к файлу с контактами. По умолчанию используется `./contacts.json`.

## Управление

- `a` - добавить новый контакт;
- `f` - открыть поиск;
- `e` - выйти из режима поиска к общему списку;
- `q` - сохранить изменения и завершить программу.

## Формат файла контактов

Приложение работает с JSON-массивом объектов следующего вида:

```json
[
    {
        "id": 0,
        "name": "Иван",
        "number": "+7 900 000-00-00",
        "comment": "Коллега"
    }
]
```

## Примечание

Если указанный JSON-файл не существует, приложение создаст пустую базу контактов в памяти и сможет сохранить её в этот файл при выходе.
